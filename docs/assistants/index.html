Connected assistants

Stored in your account and on your devices. Available to the assistants you connect. We don't sell your tasks, use them for ads or train models on them. Your calendar stays on your iPhone unless you choose to share busy times.

The connector address is https://mcp.daytulo.com/mcp. It uses OAuth. You approve the connection in the Daytulo app with the eight-digit code under Rhythm → Connected assistants.

What an assistant can do

You grant scopes. A connection that can only add tasks cannot read your plan. A read-only connection cannot add, change or delete tasks.

  • Add tasks (tasks:add). Create a task. Read: no. Write.
  • Read tasks (tasks:read). List and open tasks and projects. Read.
  • Change tasks (tasks:write). Update, complete, reschedule, restore, and delete. Delete is a sensitive write: the assistant must confirm, and the task goes to Recently deleted for 30 days.
  • Read the plan (plan:read). Today’s plan and suggested slots. Read.
  • Busy times (calendar:freebusy). Start and end only, when you share busy times. Read.
  • Calendar titles (calendar:details). Titles as well, only if you share titles and tick this box. It is off unless you opt in. Read.

Set up

Claude. Add a custom connector with the address above. Claude’s directory listing, when it is published, uses the same address. Approve the code in Daytulo.

ChatGPT. Add Daytulo as a connector with the same address. Approve the code in Daytulo. The terms for that listing are these terms.

Muse. Add the Daytulo connector from Muse when it is listed, or the address above. A read-only grant is available: read tasks, the plan and busy times, with no add or delete.

Grok Bot. Install the Daytulo plugin from the Cursor Marketplace when it is published. The plugin points at the same address. grok.com can also add https://mcp.daytulo.com/mcp as a custom connector. Approve the code in Daytulo.

Revoke

Open Daytulo, go to Rhythm, then Connected assistants, and remove the connection. That stops the assistant immediately. Removing the app from the assistant’s own settings does not by itself delete tasks already written.

Limits

Ten connected assistants per account. Twenty-five changes in one batch. A delete, or a batch of more than ten changes, asks the assistant to confirm before anything is written. Task titles are limited to 200 characters. Notes are limited to 100 KB.
